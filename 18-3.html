基于知识库的智能客服系统架构图（SVG）

纯 SVG 绘制 · 科研方向：NLU 语言理解 → RAG 知识检索增强 → 答案生成 → 评估与持续学习闭环 · 鼠标悬停模块可高亮

科研方向说明

① 自然语言理解（NLU）：意图识别（BERT / TextCNN）、命名实体识别（BiLSTM-CRF）、情感分析，是客服机器人"听懂用户"的基础。

② 检索增强生成（RAG）：Sentence-BERT 向量化 + Milvus 相似度检索 + 知识图谱多跳推理，解决大模型幻觉与领域知识不足问题。

③ 评估与持续学习闭环：准确率 / 召回率 / F1 量化评估 → 人工标注 badcase → 模型微调迭代，左侧青色箭头即闭环通路。

④ 相比 18-2 的 Canvas 绘图，本页使用 SVG：矢量缩放不失真、原生 <title> 悬停提示、CSS 即可驱动虚线流动动画。
