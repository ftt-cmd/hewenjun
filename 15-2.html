JavaScript 条件与循环

① if / else if / else

根据考试成绩（0~100）划分等级。点击按钮随机生成成绩并判定。

② switch

根据数字 1~7 输出对应的星期几。

③ for 循环 — 九九乘法表

两层 for 循环输出完整九九乘法表。

④ while 循环 — 猜数字

生成 1~100 随机数，模拟多次猜测直到猜中为止。

⑤ do-while 循环 — 累加求和

计算 1 + 2 + 3 + … + N，直到和超过 200 时停止。

⑥ break / continue — 素数过滤

1~30 中，跳过偶数（continue），遇到超过 25 时停止（break），输出剩余素数。
