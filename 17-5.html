JavaScript 两种定时器

setTimeout（一次性定时器）与 setInterval（循环定时器），通过 clearTimeout / clearInterval 取消

① 两种定时器对比

setTimeout 一次性setInterval 循环
触发次数延迟指定毫秒后触发 1 次每隔指定毫秒触发，无限次
语法var id = setTimeout(fn, 毫秒)var id = setInterval(fn, 毫秒)
取消方法clearTimeout(id)clearInterval(id)
返回值定时器编号 id（数字），用于取消定时
典型场景延迟提示、广告弹窗、防抖秒表、轮播图自动播放、实时时钟
