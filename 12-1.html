什么是 CSS 变量？

CSS 变量（又称自定义属性）允许你定义可重复使用的值，并在整个样式表中引用它们。使用 var() 函数来引用变量值。

定义的变量

  • --yuan-primary-color : #3498db - 主题色
  • --yuan-secondary-color : #2ecc71 - 辅助色
  • --yuan-bg-color : #f5f5f5 - 背景色
  • --yuan-text-color : #333 - 文字颜色
  • --yuan-font-size : 18px - 字体大小
  • --yuan-border-radius : 8px - 圆角
  • --yuan-padding : 20px - 内边距
  • --yuan-margin : 15px - 外边距

代码示例

/* 在 :root 中定义变量 */ :root { --yuan-primary-color: #3498db; --yuan-secondary-color: #2ecc71; --yuan-bg-color: #f5f5f5; } /* 使用 var() 引用变量 */ .yuan_box { background-color: var(--yuan-primary-color); padding: var(--yuan-padding); border-radius: var(--yuan-border-radius); }

CSS 变量的优势

1. 便于维护：修改变量值即可全局生效

2. 主题切换：通过更改变量实现暗色/亮色主题

3. 代码复用：避免重复书写相同的值

4. 动态修改：可通过 JavaScript 动态改变
