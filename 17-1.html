JSON 数据格式

JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，独立于语言、易于读写，是前后端数据通信的事实标准。

① JSON 语法规则

规则说明示例
数据是键值对键必须是双引号字符串"name": "袁磊"
数据由逗号分隔最后一个成员后不能有逗号{"a":1, "b":2}
花括号保存对象无序键值对集合{"id": 1}
方括号保存数组有序值集合，可与对象嵌套[1, "two", true]
不支持注释 / 函数 / undefined纯数据，比 JS 对象字面量更严格// 注释非法

② JSON 的六种数据类型

{
  "str":  "字符串（必须双引号）",
  "num":  3.14,
  "bool": false,
  "null": null,
  "obj":  { "city": "北京" },
  "arr":  [10, 20, 30]
}

③ JSON.stringify()：JS 对象 → JSON 字符串

var book = { name: "三体", price: 45.5, tags: ["科幻", "小说"] };
var json = JSON.stringify(book, null, 2);   // 缩进 2 空格美化输出
点击按钮运行…

④ JSON.parse()：JSON 字符串 → JS 对象

var json = '{"name":"袁磊","age":20,"skills":["HTML","CSS","JS"]}';
var obj  = JSON.parse(json);
obj.skills[1];   // → "CSS"
点击按钮运行…
