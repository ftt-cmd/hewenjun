Mermaid — 智能客服系统流程图与 ER 图

使用 mermaid 的 flowchart（业务流程）与 erDiagram（数据库实体关系）两种图型，文本即图表，脚本本地化于 ./cdn/

① 智能客服业务流程图 flowchart TD

用户提问 → 预处理 → 意图识别 → 置信度分流：命中知识库直接作答并满意度回访，未命中则多轮澄清后转人工并生成工单
flowchart TD
    A[用户发起咨询] --> B[输入预处理
去噪 / 分词 / 脱敏]
    B --> C[意图识别 NLU
分类 + 实体抽取]
    C --> D{"置信度 ≥ 0.85 ?"}
    D -- 是 --> E[知识库检索
向量匹配 Top-K]
    E --> F[答案组装与润色]
    F --> G{"内容安全审核
通过 ?"}
    G -- 是 --> H[回复用户]
    H --> I[满意度评价收集]
    I -- 满意 --> J[(会话归档入库)]
    I -- 不满意 --> K
    D -- 否 --> K[多轮澄清追问]
    K --> L{"澄清后命中 ?"}
    L -- 是 --> E
    L -- 否 --> M[转接人工坐席]
    M --> N[生成服务工单]
    N --> O[人工处理并回复]
    O --> J
    G -- 否 --> P[拦截并提示换一种问法]
    P --> B

② 智能客服数据库 ER 图 erDiagram

用户 → 会话 → 消息 的核心链路；知识分类 → 知识条目 支撑检索；会话可升级生成 工单，由 坐席 处理
erDiagram
    USER ||--o{ SESSION : starts
    SESSION ||--o{ MESSAGE : contains
    SESSION ||--o| TICKET : escalates
    AGENT ||--o{ TICKET : handles
    CATEGORY ||--o{ KB_ENTRY : groups
    KB_ENTRY ||--o{ MESSAGE : answers
    USER {
        bigint user_id PK "用户ID"
        varchar nickname "昵称"
        varchar phone "手机号"
        datetime created_at "注册时间"
    }
    SESSION {
        bigint session_id PK "会话ID"
        bigint user_id FK "所属用户"
        varchar channel "来源渠道"
        tinyint status "0进行中1已结束"
        datetime started_at "开始时间"
    }
    MESSAGE {
        bigint msg_id PK "消息ID"
        bigint session_id FK "所属会话"
        bigint kb_id FK "命中的知识条目"
        tinyint role "0用户1机器人2坐席"
        text content "消息内容"
        tinyint satisfaction "满意度-1未评0-5分"
    }
    KB_ENTRY {
        bigint kb_id PK "知识条目ID"
        bigint category_id FK "所属分类"
        varchar title "标准问题"
        text answer "标准答案"
        int hit_count "命中次数"
    }
    CATEGORY {
        bigint category_id PK "分类ID"
        varchar name "分类名称"
    }
    TICKET {
        bigint ticket_id PK "工单ID"
        bigint session_id FK "来源会话"
        bigint agent_id FK "受理坐席"
        tinyint status "0待处理1处理中2已完成"
        varchar summary "问题摘要"
    }
    AGENT {
        bigint agent_id PK "坐席ID"
        varchar name "坐席姓名"
        tinyint online "是否在线"
    }

实现说明

① mermaid：使用 JS 语法描述图表（图表即代码），页面引入本地化的 mermaid.min.js 后调用 mermaid.initialize({ startOnLoad: true })，自动把 <pre class="mermaid"> 内文本渲染为 SVG。

② flowchart：TD 自上而下布局，节点用 []（处理）、{}（判定）、[()]（数据库）、(()) 等形状区分语义，--> 连线并支持 |标签| 分支文字，style 自定义高亮配色。

③ erDiagram：||--o{ 等乌鸦脚标记表达 一对一 / 一对多 关系，实体块内声明 类型 名称 PK/FK "注释"，自动布局生成实体关系图。
