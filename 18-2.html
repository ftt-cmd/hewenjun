基于 Canvas 的电商系统全站架构图

纯 Canvas 2D 绘制：六层架构、请求/响应数据流动画（虚线流动 + 流光粒子），鼠标悬停模块可高亮。

架构说明

① 用户层 → 接入层：请求经 CDN、负载均衡、API 网关进入系统；② 业务服务层：用户 / 商品 / 订单 / 支付 / 库存 / 搜索六大微服务；③ 中间件层：Redis 缓存、消息队列削峰、ES 搜索；④ 数据层：MySQL 主从、MongoDB、OSS；⑤ 基础设施：Docker 容器集群与监控告警兜底。

动画原理：ctx.setLineDash + lineDashOffset 让虚线流动表示请求链路，requestAnimationFrame 驱动流光粒子沿连线往返。
